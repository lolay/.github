# lolay

Open source tools from lolay.

- [nowline](https://github.com/lolay/nowline): Roadmaps as code. A plain-text language for product and engineering roadmaps, rendered to timelines and exported to SVG, PDF and MS Project XML. Site: [nowline.io](https://nowline.io).
- [ghx](https://github.com/lolay/ghx): Clones and refreshes all repos for a GitHub organization, and only fast-forwards a clone when that loses no local work.
- [triage](https://github.com/lolay/triage): The environment doctor. Declarative checks that a project's tools, versions, environment variables and files are in place before a build, CI run or release.
- [agent-images](https://github.com/lolay/agent-images): macOS and Linux/Android VM images for self-hosted Claude Code runners, one VM per session.

Want to contribute? Start with [CONTRIBUTING.md](https://github.com/lolay/.github/blob/main/CONTRIBUTING.md), or the project's own if it has one.
